# Phase 1: 识别意图 + 解析时间

## 识别分支

读用户消息，判断走哪个分支（可同时多个）：

| 用户说... | 走分支 | 加载文件 |
|---|---|---|
| "加日历"、"加事件"、"明天X点开会"、"add to calendar" | calendar | `phases/calendar.md` |
| "提醒我"、"添加提醒"、"提醒事项"、"remind me" | reminder | `phases/reminder.md` |
| "发通知"、"显示通知"、"弹个通知"、"show notification" | notification | `phases/notification.md` |
| "今日日程"、"今天有什么"、"我今天的日历" | query | `phases/query.md` |

如用户同时要多项（如"提醒我开会，并加到日历"），后续按顺序逐项执行。

## 解析时间

把口语时间转成 macOS AppleScript 接受的格式：
- 标准：`"YYYY-MM-DD HH:MM:SS"`（如 `"2026-04-28 19:00:00"`）
- 英文：`"April 28, 2026 19:00:00"` 也接受

## 缺失信息处理

如缺关键参数，主动问用户：
- 日期（具体哪一天）
- 开始时间 / 结束时间（仅日历事件需要）
- 标题 / 内容
- 用哪个日历名 / 提醒列表名（不确定时先列出）

## 契约.post

- 已确定要走哪个（或哪几个）分支
- 已收集执行所需的全部参数（时间已转标准格式、标题确定、列表名确定）
